# OWNER.md — who this vault belongs to

`AGENTS.md` holds the rules every vault built from this template shares. This
file holds what is particular to its owner. Agents read it second, after
`AGENTS.md` and before `index.md`. Where the two disagree on a matter of taste,
this file wins; on a matter of safety or privacy, `AGENTS.md` wins.

`SETUP.md` fills this file in by interviewing the owner. Edit it by hand at any
time. Keep it short: an agent reads it at the start of every session.
