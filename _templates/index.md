# Templates

Copy the matching template when creating a note. `type` is the only required
field; write the others unless there is a reason not to.

- [topic.md](topic.md) — durable know-how.
- [project.md](project.md) — a time-bounded effort; state above the timeline line, dated record below.
- [person.md](person.md) — a colleague or an influence; same two zones.
- [decision.md](decision.md) — one decision, the options and what would reopen it.
- [source.md](source.md) — an immutable source in `raw/`.
